## 2024-05-23 - [Jekyll & Minimal Mistakes]
**Learning:** This repo uses Jekyll with the "Minimal Mistakes" remote theme. Most UI components are hidden in the gem, but `resume.html` is a standalone file that bypasses the theme, making it a prime candidate for direct accessibility improvements without fighting theme overrides.
**Action:** When improving static sites using themes, look for "orphan" pages or custom layouts first, as they are often neglected and easier to modify than theme-locked components.
